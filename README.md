# savour. 🍽️

**A private, photographic food journal built in Flutter.**

Photos are the point: capture your meals, optionally name them, add a short memory, and browse them in an editorial-style album or calendar. No account and no remote backend.

## Included in this first build

- **Photo-first album:** two-column, varied-height gallery grouped by month. Tap a photo to view its uncropped original full-screen.
- **Full-screen viewer:** pinch to zoom up to 5×, double-tap to zoom/reset, swipe between the current album or day’s photos, tap to hide controls, and open meal details from the info button.
- **Capture or import:** iOS and Android camera, gallery picker on supported platforms.
- **Optional name and notes:** no form field is required; just a photo.
- **Editable timestamp:** current date/time is prefilled and can be changed.
- **Calendar:** month browser with indicators on days that have saved meals.
- **Search and favourites:** find dishes and important memories.
- **Edit/delete:** update notes/date, favourite moments, delete individual entries or wipe the vault.
- **Private on-device storage:** AES-256-GCM encrypted original photos, thumbnails and journal index, with random per-blob nonces; a 256-bit key is held in system secure storage.
- **Optional app lock:** device biometrics/PIN/passcode on supported Android and iOS devices; covers every in-app route.
- **Custom launcher icon** and a warm editorial, camera-first UI.

## Quick start

Flutter SDK **3.35 or newer** is recommended (Dart 3.9+). Have Android Studio for Android development, and Xcode on macOS for iOS. Linux desktop development is optional.

```bash
unzip savour_flutter.zip
cd savour_flutter
bash tool/setup_platforms.sh
flutter devices
flutter run -d <your-device-id>
```

The setup script creates native Android/iOS/Linux runners using the installed Flutter SDK, restores the supplied app code, configures camera/photo/Face ID permissions, sets Android's minimum SDK to 24, disables Android auto-backup, fetches packages, and installs the launcher icons.

To check code and build an Android debug APK:

```bash
dart format lib test
flutter analyze
flutter test
flutter build apk --debug
```

APK output: `build/app/outputs/flutter-apk/app-debug.apk`. A GitHub Actions workflow performs the same checks/build and can provide an APK as an Actions artifact if you upload this project to a repository.

## App identity

Native application ID generated by the setup script: `dev.savour.savour`. If you previously installed a Morsel prototype with another application ID, Savour installs separately and its encrypted vault will not transfer automatically.

## Storage design

```text
application-support/savour_vault/
   journal.mor              encrypted metadata index (JSON, authenticated)
   <id>.photo.mor           encrypted original image
   <id>.thumb.mor           encrypted resized thumbnail

platform secure storage:
   savour.v1.key            random 256-bit AES key
   savour.v1.appLock        lock preference
```

The journal itself, including titles, description, timestamp and favourites, is encrypted. A corrupt index or missing key produces a visible error **without wiping the data**. Writes use a temporary file and rename.

**Important privacy/backup notes:**

1. **No backup/export in v0.1.** Uninstalling the app or losing/resetting a device can permanently lose these meals. Back up original images separately until encrypted export/restore is implemented. Do not rely on this app as the only copy of irreplaceable photos.
2. Imported originals already in Apple Photos/Android Gallery remain there. Savour encrypts its *own copy*, not the source photo. OS image pickers may temporarily cache unencrypted copies; Savour removes a picked image when it is within the app's identified temporary directory. This app cannot guarantee removal of copies maintained by the OS or other apps.
3. Device operating-system backups may have platform-specific behaviour. Android's app auto-backup is disabled in the native setup. This build does not implement cloud syncing.
4. A lost Keychain/Keystore key makes the encrypted vault unreadable. Savour intentionally refuses to create a replacement key over existing encrypted data.
5. Large photos are decrypted in process memory when displayed. This version is intended for personal use and has **not** undergone an external security audit.
6. Some HEIC/HEIF files may not decode on every platform. When importing, using the image picker's resizing options typically produces compatible images; test with your device.

## Architecture

- `lib/models/food_entry.dart`: immutable entry and JSON representation.
- `lib/services/vault_cipher.dart`: authenticated encryption/decryption.
- `lib/services/vault_repository.dart`: encrypted local file persistence, thumbnail generation, change notifications.
- `lib/screens/`: album, calendar, full-screen zoomable viewer, add/edit, photo details, privacy and settings.
- `lib/theme/`, `lib/widgets/`: design system, reusable image loader and empty state.
- `test/`: encryption round-trip/tampering, model tests and photo viewer widget tests.
- `tool/`: repeatable native Flutter bootstrap and platform permissions.
